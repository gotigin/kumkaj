# Khaynjo privacy policy

_Last updated: 9 November 2026_

## Who we are

Khaynjo is a restaurant operating app from Gotigin under the Kumkaj brand.
Application id on Google Play: `com.khaynjo`. Website: [khaynjo.com](https://khaynjo.com).

## Local-first — what stays on your device

Khaynjo is built for **offline / local use**. Shop books — menu, tables, orders,
kitchen tickets, day book, sales, credit, staff, settings — are stored **on the
devices where you install Khaynjo**.

- You do **not** need a Kumkaj account to use the app locally.
- We do **not** require cloud sync for billing or day-to-day till use.
- Optional Kumkaj Cloud (if offered later) will be separate and opt-in.

## What the app stores

Typical data on the device includes:

- Business setup (shop name, tax / country settings, printers)
- Menu, prices, photos you add
- Orders, payments, party credit, expenses, stock figures
- Staff names, roles, and **PIN / password hashes** (not plaintext PINs)
- Local backup copies under the app’s data folder

Uninstalling the Android app usually **deletes** this on-device data. Save a
backup before you uninstall or change phones.

## Backups you export

From Settings → Backup you can save a backup file (SQLite). That file is a
**full copy of the shop books** and is **not encrypted**. Treat it like the
cash box: store it only where the owner trusts (phone storage, USB, your Drive).
Anyone with the file can read trading history; short PIN hashes can be attacked
offline — change PINs if a backup leaks.

## What leaves the device

Data leaves the device only when **you** choose to, for example:

- **Save a backup copy…** / restore from a file you pick
- Share or print a bill / receipt (system share sheet or a printer you configure)
- Pair **extra tills on your shop LAN** (Server ↔ Client on your Wi‑Fi) — traffic
  stays on your network, not a Kumkaj cloud by default
- Optional features you turn on later (e.g. cloud) — described when available

We do not sell shop data or use it for advertising.
