## The app

Khaynjo keeps menus, tables, tickets, settle and day books **on the devices you install it on**. Local use does not require a Kumkaj account. Optional shares (WhatsApp of a bill) leave the device only when you choose them.

Guest QR, kiosk and token pages — when used — run on the **restaurant Wi‑Fi**, not over mobile data as a public cloud menu.

## This website

khaynjo.com is static. We aim to use cookieless analytics when hosted — no advertising trackers.
