# Catalogue templates (Tabiyat)

Tabiyat ships **empty**. The owner adds their own medicines — there is no
restaurant starter catalogue and no bundled pharmacy drug database.

Optional future: drop a folder `assets/templates/<id>/template.json` for a
named import. Discovery is automatic via `menu_templates`. Until then this
directory stays intentionally empty of product catalogues. Schedule H / Rx
flags remain owner bookkeeping, never a compliance pack.
