## The app

Tabiyat keeps the medicine list, batches, sales, khata and day books **on the devices you install it on**. Local use does not require a Kumkaj account. Optional shares (WhatsApp of a bill) leave the device only when you choose them.

Customer pages — when used — run on the **shop Wi‑Fi**. They are not a public cloud catalogue.

## This website

tabiyat.com is static. We aim to use cookieless analytics when hosted — no advertising trackers.
