## The app

Moklanjo keeps courier books, bookings, AWB data and day books **on the devices you install it on**. Local use does not require a Kumkaj account. Optional shares (WhatsApp receipt, copied SMS text) leave the device only when you choose them.

Public track‑by‑AWB pages, when enabled, run on the **office Wi‑Fi** — not over the public internet.

## This website

moklanjo.com is static. We aim to use cookieless analytics when hosted — no advertising trackers.
