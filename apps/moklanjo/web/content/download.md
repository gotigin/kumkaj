Moklanjo runs on **Android**, **Windows** and **Linux**. Downloads go live here after each package passes a clean‑machine install check.

Until then:

- Build artefacts stay in the repo’s `dist/` for developers
- Play Store listing text is in this site’s `play-store-listing.txt`
- First‑run Owner PIN set‑up is explained **in the app and install guide**, not on the home page

System needs and SHA‑256 sums will appear next to each file when releases are published.
