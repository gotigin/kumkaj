## The apps

Moklanjo and Khaynjo keep shop data — sales, parties, menus, day books — **on the devices you install them on**. Local use does not require a Kumkaj account. Optional shares (for example WhatsApp of a receipt) leave the device only when you choose them.

## This website

kumkaj.com is a static site. We aim to use **cookieless** analytics (for example Cloudflare Web Analytics) when hosted — no advertising trackers, no cookie banner for third‑party ads.

Contact links may open WhatsApp or your mail app. We do not run a lead form on this static host yet.
