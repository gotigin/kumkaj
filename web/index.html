Get builds from kumkaj.com. Packaging scripts land artifacts in dist/. iOS / macOS App Store builds are deferred until a Mac signing host is available.

  • Android — Play Store / sideload APK via ./apps/moklanjo/scripts/package-android.sh (id com.moklanjo)
  • Linux — ./apps/moklanjo/scripts/package-linux.sh → dist/linux/kumkaj
  • Windows — ./apps/moklanjo/scripts/package-windows.sh → dist/moklanjo-windows/
  • Website — deploy web/ (or dist/web/) to https://kumkaj.com
